# Сборка и прошивка

Проект собирается PlatformIO. Arduino IDE больше не используется.

## Команды

```bash
pio run                                     # собрать прошивку
pio run --target upload                     # прошить по USB
pio run --target uploadfs                   # залить фронтенд в LittleFS
pio run --target buildfs                    # только собрать образ LittleFS
pio test -e native                          # тесты логики на хосте
pio run --target erase                      # СТЕРЕТЬ ВСЁ, включая настройки
```

Порт задаётся явно, если плат несколько:

```bash
pio run --target upload --upload-port COM3
```

Полная последовательность после изменений и в прошивке, и в интерфейсе:

```bash
pio run --target upload --upload-port COM3
pio run --target uploadfs --upload-port COM3
```

`uploadfs` нужен хотя бы один раз на новой плате, иначе страница откроется с
сообщением о незалитом фронтенде.

## Что переживает перепрошивку

| | `upload` | `uploadfs` | `erase` |
|---|---|---|---|
| Прошивка | заменяется | — | стирается |
| Фронтенд (LittleFS) | сохраняется | заменяется | стирается |
| Настройки (EEPROM) | сохраняется | сохраняется | стирается |

Это обеспечено разметкой `eagle.flash.4m2m.ld` и строкой
`board_upload.erase_cmd =` в `platformio.ini`. Проверено на плате: после
`upload` устройство подняло сохранённую сеть без перенастройки.

## Расход памяти

На момент последней проверки:

```
RAM:   44.0% (36048 из 81920 байт)
Flash: 40.1% (419037 из 1044464 байт)
```

Свободная куча в работе — около 38 КБ (видно в телеметрии как `heap`). Это
запас, но не повод расслабляться: падения на ESP8266 чаще происходят не от
нехватки памяти, а от нехватки **непрерывного куска**.

## OTA по WiFi

Раскомментируйте в `platformio.ini`:

```ini
upload_protocol = espota
upload_port = 192.168.88.xx
```

Адрес устройства виден на вкладке «Светильник» и в `GET /api.json`.

Можно и напрямую, не трогая конфиг:

```bash
python ~/.platformio/packages/framework-arduinoespressif8266/tools/espota.py \
  -i 192.168.88.20 -f .pio/build/d1_mini/firmware.bin -r
```

Проверено на плате: обновление проходит, устройство перезагружается и
возвращается в сеть с сохранёнными настройками.

**Отката не существует.** A/B-слотов на ESP8266 нет: `ArduinoOTA` пишет образ
во временную область, а загрузчик `eboot` при перезагрузке копирует его
поверх старой прошивки. Старой версии после этого физически нет. Прошивка,
падающая до `loop()`, восстанавливается только по USB.

## Serial

115200 бод. Полезно при первом включении и при отладке WiFi:

```bash
pio device monitor -p COM3 -b 115200
```

Кодировка вывода — UTF-8. В PowerShell для читаемости кириллицы:
`$env:PYTHONIOENCODING='utf-8'`, а сам монитор лучше запускать в терминале с
UTF-8 кодовой страницей.
