# Правила работы над SmartNightLight — GigaCode/GigaCod

Канонический файл правил — [../CLAUDE.md](../CLAUDE.md). Он один, чтобы две
копии не разъехались. Прочитайте его целиком, затем
[../docs/_index.md](../docs/_index.md) — карту документации.

Кратко, чтобы не читать дважды:

- Читайте только ту документацию, которая относится к задаче.
- Перед отладкой — `docs/pitfalls.md`.
- Логика светильника (`NightLight.h`) не зависит от Arduino: на этом держатся
  тесты.
- Новые поля `ConfigData` — только в конец структуры.
- В колбэке WebSocket только помечаем работу, выполняем её в `loop()`.
- Пароли клиенту не отдаём и в репозиторий не коммитим.
- Точка доступа — `192.168.0.1`, не `192.168.4.1`.
- Документацию обновляем сразу после кода, запись — в `CHAT_SUMMARY.md`.
- Коммиты: `fix:`, `feat:`, `docs:`, `refactor:`, `chore:`, в теле — почему.
- Прошивка: `pio run -t upload --upload-port COM3`, фронтенд —
  `pio run -t uploadfs --upload-port COM3`.
